# Snipvero 0.1.0 Beta 7

This maintenance beta updates the development toolchain for GHSA-p4f5-76q4-ffq7.
Installed desktop apps are not affected by this development-server vulnerability.

## Security

- Vite 8.3.5 and Rolldown 1.2.15 are replaced by Vite 8.3.7 and Rolldown 1.2.18.
- A Vite development server exposed to the network could allow arbitrary file reads and code
  execution. Snipvero's default development configuration is local-only, but `TAURI_DEV_HOST`
  set to a network address or Vite's `--host` can expose it.
- Contributors must update their source checkout and run `pnpm install`; updating only the
  installed app does not update a separate development checkout.
- Published desktop apps load bundled frontend files, not a Vite development server. No desktop
  runtime vulnerability or exploitation has been established by this review.
- Advisory: https://github.com/vitejs/vite/security/advisories/GHSA-p4f5-76q4-ffq7

## Privacy

No new runtime dependency, data collection or network connection is added. Screenshots,
annotations and file names stay on your Mac. Update checks run only when you ask.

## Updating and installation

- **Beta 3 or later:** use **Check for Updates…** in the main window or About, then
  **Download and Restart**. Finish or cancel an active capture first.
- **Beta 2 or earlier / new installation:** download `Snipvero_0.1.0-beta.7_aarch64.dmg`,
  move **Snipvero** to **Applications**, and launch it.
- Requires macOS 14 or later on Apple silicon. Intel Macs and Windows are not supported.

Download `SHA256SUMS.txt` alongside the DMG and check it in Terminal:

```sh
grep 'Snipvero_0.1.0-beta.7_aarch64.dmg$' SHA256SUMS.txt | shasum -a 256 -c -
```

## Verification limits

Development-server regression tests and automated checks are recorded with the release change.
Clean-Mac quarantined first launch and Homebrew install/upgrade remain unverified. Windows CI
checks compilation, tests and smoke packaging, not Windows runtime support.
