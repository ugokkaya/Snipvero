# Snipvero 0.2.0 Beta 1

Snipvero can now record a region of your screen as a video or a GIF, hide sensitive areas of a
screenshot, and speaks Turkish.

## Added

- **Screen recording (macOS):** record any area of one display as an MP4 (H.264, 30 fps). Start it
  from **Record Region** in the menu bar or the main window, or from the record button of the
  screenshot toolbar. Stop it with the **Stop** button beside the clock, the menu bar, the capture
  shortcut or the maximum length (five minutes by default). A review window plays the recording and
  offers Save, Copy File, Copy Path and Discard. The recording is a private temporary file, deleted
  when you save or discard it, when you quit and at the next launch.
- **Sound (optional):** system audio and the microphone are two separate switches in the main
  window, both off by default. The microphone prompt appears only when you turn it on.
- **GIF export:** **Export as GIF…** in the recording window. Choose 5, 10 or 15 frames per second
  and a width up to 800 pixels. The window shows the output size and an estimate, then progress, with
  Cancel. GIFs are made from at most 60 seconds of video; the MP4 is not changed.
- **Fill, Blur and Highlight:** cover an area with a solid fill, turn it into mosaic blocks that
  cannot be undone in the exported image, or tint it with a translucent highlight.
- **Turkish interface:** the app follows your system language. The **Language** row in the main
  window switches between System default, English and Türkçe without a restart. The macOS
  microphone permission text stays English.

## Changed

- Capture reuses the display list instead of asking the system for it on every capture.

## Privacy

No telemetry, upload or network path is added. Recordings and screenshots stay on your Mac until
you save or copy them. Update checks run only when you ask. The app now carries one entitlement,
`com.apple.security.device.audio-input`, and a microphone usage text; the system asks for the
microphone only when you turn it on.

## Updating and installation

- **Beta 3 or later:** use **Check for Updates…** in the main window, About or menu bar, then
  **Download and Restart**. Finish or cancel any active capture or recording first.
- **Beta 2 or earlier / new installation:** download `Snipvero_0.2.0-beta.1_aarch64.dmg`, move
  **Snipvero** to **Applications**, and launch it.
- Requires macOS 14 or later on Apple silicon. Intel Macs and Windows are not supported.
- The signing certificate is unchanged, so Screen Recording stays allowed. Allow the microphone only
  if you use it.

Download `SHA256SUMS.txt` alongside the DMG and check it in Terminal:

```sh
grep 'Snipvero_0.2.0-beta.1_aarch64.dmg$' SHA256SUMS.txt | shasum -a 256 -c -
```

## Verification limits

The maintainer checked recording, sound, GIF export, the mosaic tools and the Turkish interface in
a locally built macOS app and found them working. This is not a claim of exhaustive testing: macOS
14 and 15, mixed-display and Retina-versus-standard setups, denied or revoked permissions, long
recordings, a clean-Mac quarantined first launch and Homebrew install/upgrade remain unverified.
Windows CI checks compilation, tests and smoke packaging, not Windows runtime support.
