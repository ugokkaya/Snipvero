# Snipvero 0.1.0 Beta 2

This beta improves PNG save safety and macOS distribution. No new capture or annotation features
are introduced.

## Security fixes

- Create PNG save temporary files exclusively with unique names, preventing pre-existing
  temporary-file symlinks from redirecting writes to another file.
- Preserve restrictive Unix permission bits when replacing an existing regular PNG file.
- Update the development-only minimatch dependency to address GHSA-g3hv-75wg-m249.

## macOS distribution

- Developer ID Application signing with hardened runtime enabled.
- Apple notarization and stapled tickets for both the application and DMG.
- SHA-256 verification through `SHA256SUMS.txt`.

## Requirements and installation

- macOS 14 or later on Apple silicon (M1 or later).
- Intel Macs and Windows are not supported by this release. No universal binary is provided.
- Download `Snipvero_0.1.0-beta.2_aarch64.dmg`, move **Snipvero** to **Applications**, and launch it.
- Users upgrading from the ad-hoc Beta 1 build may need to grant Screen Recording permission again
  because the signing identity has changed.

Download `SHA256SUMS.txt` into the same folder as the DMG and verify it in Terminal:

```sh
shasum -a 256 -c SHA256SUMS.txt
```

## Known limitations

- Beta software; a selection remains confined to one display.
- No Intel or Windows support in this release.
- Homebrew distribution is not yet published; a version-pinned cask is prepared separately.
