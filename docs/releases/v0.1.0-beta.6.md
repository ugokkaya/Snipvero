# Snipvero 0.1.0 Beta 6

This beta fixes a freeze of the menu bar and Dock after clicking Snipvero's menu bar icon, and
lets the capture shortcut cancel a capture.

## What's fixed

- Clicking the menu bar icon could leave Snipvero's menu open with a spinning cursor, and the menu
  bar and Dock stopped responding until Snipvero was quit. It happened while macOS was slow to
  report the **Open at Login** setting. Snipvero now reads and changes that setting in the
  background, so its menu never waits for it.

## What's new

- Pressing the capture shortcut (⌘⇧2 by default) during a capture cancels it, as Esc does. It
  works even if the capture screen stops responding. While the save dialog is open it does
  nothing, like Esc.

## Privacy

- No new data is stored and no new connection is made.
- Screenshots, annotations and file names stay on your Mac.
- Snipvero connects for updates only when you click **Check for Updates…**; downloading and
  installing require **Download and Restart**.

## Updating and installation

- **Beta 3 to Beta 5:** use **Check for Updates…** in the main window or About. If the menu bar
  menu freezes on Beta 5, use the main window instead (open Snipvero from Applications). Finish or
  cancel an active capture before installing. The update is signed and verified before
  installation.
- **Beta 2 or earlier:** install this version from its DMG once; later updates can be installed
  from within the app.
- **New installation:** download `Snipvero_0.1.0-beta.6_aarch64.dmg`, move **Snipvero** to
  **Applications**, and launch it. Grant Screen Recording permission if requested.
- Requires macOS 14 or later on Apple silicon (M1 or later). Intel Macs and Windows are not
  supported by this release.

Download `SHA256SUMS.txt` alongside the DMG, then verify it in Terminal:

```sh
grep 'Snipvero_0.1.0-beta.6_aarch64.dmg$' SHA256SUMS.txt | shasum -a 256 -c -
```

The checksum file also lists the updater package; this command checks only the DMG.

## Verification limits

Both changes were checked on macOS Apple silicon with the notarized build before this release.
The original freeze depended on how quickly macOS answered and could not be reproduced on demand,
so the fix rests on the cause found in the code and logs. A clean-Mac quarantined first launch and
Homebrew install/upgrade remain unverified. Windows CI is a compile/test/smoke check, not Windows
runtime support.
