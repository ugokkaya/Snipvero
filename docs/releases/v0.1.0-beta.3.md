# Snipvero 0.1.0 Beta 3

This beta adds in-app updates: Snipvero can check for a newer version from its About window and
install it after you agree, verifying the update's signature first. It only connects to the
internet when you click Check for Updates.

## In-app updates

- **Check for Updates…** in the Snipvero window's new **Updates** row (also in About Snipvero and
  the menu bar menu) shows whether a newer beta exists, with its release notes. Nothing is downloaded until you click **Download and Restart**.
- Every update is verified with Snipvero's update signing key, for exactly the announced version,
  before it is installed. An update that fails verification is never installed.
- Snipvero does not update while a capture is open, and the running version keeps working if a
  download or installation fails or is cancelled.
- If Snipvero is in a folder you cannot write to, macOS asks for an administrator password in its
  own dialog; Snipvero never sees the password.

## Privacy

- Snipvero never checks for updates on its own: not at launch, not in the background.
- A check asks GitHub over HTTPS for a small file describing the newest beta; an accepted update
  is downloaded from the GitHub release. These requests carry no version number, identifier or
  cookie. As with any web request, GitHub can see your IP address, the time and the updater's
  User-Agent.
- Screenshots, annotations and file names never leave your Mac.

## Upgrading from Beta 2 or earlier

Beta 2 and earlier cannot update themselves. Install this beta once from its DMG; later versions
can then be installed from the About window. Your Screen Recording permission is expected to
carry over from Beta 2, because the signing identity is the same.

## Requirements and installation

- macOS 14 or later on Apple silicon (M1 or later).
- Intel Macs and Windows are not supported by this release. No universal binary is provided.
- Download `Snipvero_0.1.0-beta.3_aarch64.dmg`, move **Snipvero** to **Applications**, and launch it.

Download `SHA256SUMS.txt` into the same folder as the DMG and verify it in Terminal:

```sh
grep 'Snipvero_0.1.0-beta.3_aarch64.dmg$' SHA256SUMS.txt | shasum -a 256 -c -
```

The checksum file also lists the updater package; the command above checks only your DMG.
