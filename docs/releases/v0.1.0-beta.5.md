# Snipvero 0.1.0 Beta 5

This beta adds Open at Login, so the capture shortcut works as soon as you log in. Snipvero then
starts quietly in the menu bar, without opening its window.

## What's new

- **Open at Login** in the menu bar menu turns it on or off; it is off until you choose it.
- Opened at login, Snipvero shows only its menu bar icon. Opening it yourself shows the window as
  before.
- Snipvero is listed in System Settings › General › Login Items, where you can also turn it off.
  The menu shows the current setting. If you turned it off there, choosing **Open at Login** opens
  that page, because only you can allow it again.

## Privacy

- The setting is kept by macOS, not by Snipvero; no new file is written.
- Screenshots, annotations and file names stay on your Mac.
- Snipvero connects for updates only when you click **Check for Updates…**; downloading and
  installing require **Download and Restart**.

## Updating and installation

- **Beta 3 or Beta 4:** use **Check for Updates…** in the main window, About or the menu bar.
  Finish or cancel an active capture before installing. The update is signed and verified before
  installation.
- **Beta 2 or earlier:** install this version from its DMG once; later updates can be installed
  from within the app.
- **New installation:** download `Snipvero_0.1.0-beta.5_aarch64.dmg`, move **Snipvero** to
  **Applications**, and launch it. Grant Screen Recording permission if requested.
- Requires macOS 14 or later on Apple silicon (M1 or later). Intel Macs and Windows are not
  supported by this release.

Download `SHA256SUMS.txt` alongside the DMG, then verify it in Terminal:

```sh
grep 'Snipvero_0.1.0-beta.5_aarch64.dmg$' SHA256SUMS.txt | shasum -a 256 -c -
```

The checksum file also lists the updater package; this command checks only the DMG.

## Verification limits

Open at Login was manually checked on macOS Apple silicon with a locally signed build before this
release, including a login launch. A clean-Mac quarantined first launch and Homebrew
install/upgrade remain unverified. Windows CI is a compile/test/smoke check, not Windows runtime
support.
