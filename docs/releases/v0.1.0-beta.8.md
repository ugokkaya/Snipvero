# Snipvero 0.1.0 Beta 8

Capture dropdowns and other temporary UI with a five-second region timer. Print Screen can now
be assigned on its own, including keyboards that send it as F13 on macOS.

## Added

- Select a region and click the timer in its toolbar. Snipvero hides the frozen capture and
  returns focus to the previous app, giving you five seconds to open a dropdown or prepare the screen.
- A click-through blinking border marks the region, with a visible 5-to-1 countdown. It does not
  take keyboard focus; both indicators disappear before the fresh screenshot is taken.
- The editor reopens with the same region selected, ready to annotate, copy or save. Previous
  annotations and undo history are cleared because the screenshot has changed.
- Press the capture shortcut again to cancel the wait. A cancelled timer cannot reopen a later
  capture. Display arrangement, selected display resolution or scale changes end the capture
  rather than silently moving the region.

## Fixed

- Print Screen alone no longer requires modifier keys in the shortcut recorder.
- On macOS, bare F13 is also accepted for keyboards that report their Print Screen key as F13.
  It is saved and displayed as F13 so the registered shortcut matches the physical key.
- Other keys retain their modifier requirements. System or keyboard-software interception of
  Print Screen/F13 remains outside Snipvero's control.

## Privacy

No new dependency, telemetry, upload or network path is added. Screenshots remain in memory until
you explicitly copy or save them. The timer does not automatically copy or save your screenshot.
Update checks run only when you ask.

## Updating and installation

- **Beta 3 or later:** use **Check for Updates…** in the main window, About or menu bar, then
  **Download and Restart**. Finish or cancel any active capture or timer first.
- **Beta 2 or earlier / new installation:** download `Snipvero_0.1.0-beta.8_aarch64.dmg`, move
  **Snipvero** to **Applications**, and launch it.
- Requires macOS 14 or later on Apple silicon. Intel Macs and Windows are not supported.

Download `SHA256SUMS.txt` alongside the DMG and check it in Terminal:

```sh
grep 'Snipvero_0.1.0-beta.8_aarch64.dmg$' SHA256SUMS.txt | shasum -a 256 -c -
```

## Verification limits

The maintainer reported the new features working in a locally signed macOS development build,
including the keyboard that reports Print Screen as F13. This is not a claim of exhaustive native
QA for every display arrangement or keyboard. Automated checks and package verification are
recorded with the release. Clean-Mac quarantined first launch and Homebrew install/upgrade remain
unverified. Windows CI checks compilation, tests and smoke packaging, not Windows runtime support.
