# Snipvero 0.1.0 Beta 4

This beta lets you choose and save your capture shortcut from the main window. It also adds
links to the official Snipvero website and support email, while keeping screenshots local and
update checks strictly user-initiated.

## What's new

- **Global shortcut → Change…** records a new capture shortcut. **Reset to ⌘⇧2** restores the
  default. The shortcut is kept across restarts; a failed change keeps the previous shortcut.
- System-reserved combinations and common application commands are refused. A successful
  registration cannot guarantee that another app does not also use the shortcut.
- **snipvero.app** is linked from the main window and About. **Contact** in About opens
  **support@snipvero.app** in your default email app; Snipvero never sends a message itself.
- Homebrew metadata now points to the official website.

## Privacy

- The chosen shortcut is saved in `settings.json` in Snipvero's Application Support folder.
  It contains only the shortcut, never screenshots or file names.
- Screenshots, annotations and file names stay on your Mac.
- Snipvero connects for updates only when you click **Check for Updates…**; downloading and
  installing require **Download and Restart**. Website and email links open only when clicked.

## Updating and installation

- **Beta 3:** use **Check for Updates…** in the main window, About or the menu bar. Finish or
  cancel an active capture before installing. The update is signed and verified before installation.
- **Beta 2 or earlier:** install this version from its DMG once; later updates can be installed
  from within the app.
- **New installation:** download `Snipvero_0.1.0-beta.4_aarch64.dmg`, move **Snipvero** to
  **Applications**, and launch it. Grant Screen Recording permission if requested.
- Requires macOS 14 or later on Apple silicon (M1 or later). Intel Macs and Windows are not
  supported by this release.

Download `SHA256SUMS.txt` alongside the DMG, then verify it in Terminal:

```sh
grep 'Snipvero_0.1.0-beta.4_aarch64.dmg$' SHA256SUMS.txt | shasum -a 256 -c -
```

The checksum file also lists the updater package; this command checks only the DMG.

## Verification limits

The capture-shortcut UI was manually checked on macOS Apple silicon before this release.
The new website and mail-app links have automated coverage but have not been manually checked
in the packaged application. A clean-Mac quarantined first launch, Homebrew install/upgrade,
and the first update between two published releases remain unverified. Windows CI is a
compile/test/smoke check, not Windows runtime support.
