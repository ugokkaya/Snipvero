# Snipvero 0.1.0 Beta 9

Capture toolbar buttons now show reliable in-app tooltips, making each tool and its available
keyboard shortcut easier to identify.

## Fixed

- Hover over any capture toolbar button to see its name, including disabled Undo, Redo and Delete.
- Copy, Save and history actions also show their platform-specific keyboard shortcuts.
- Tooltip labels wrap and stay within the display, moving below a button when there is no room
  above it. They disappear when leaving or pressing a button and never intercept drawing input.
- Tool selection, text editing, exports and delayed capture retain their existing behaviour.

## Privacy

No new dependency, telemetry, upload or network path is added. Screenshots remain in memory until
you explicitly copy or save them. Update checks run only when you ask.

## Updating and installation

- **Beta 3 or later:** use **Check for Updates…** in the main window, About or menu bar, then
  **Download and Restart**. Finish or cancel any active capture or timer first.
- **Beta 2 or earlier / new installation:** download `Snipvero_0.1.0-beta.9_aarch64.dmg`, move
  **Snipvero** to **Applications**, and launch it.
- Requires macOS 14 or later on Apple silicon. Intel Macs and Windows are not supported.

Download `SHA256SUMS.txt` alongside the DMG and check it in Terminal:

```sh
grep 'Snipvero_0.1.0-beta.9_aarch64.dmg$' SHA256SUMS.txt | shasum -a 256 -c -
```

## Verification limits

The maintainer reported the tooltip fix working in a locally signed macOS development build.
This is not a claim of exhaustive mixed-display, keyboard or notarized-candidate runtime QA.
Automated checks and package verification are recorded with the release. Clean-Mac quarantined
first launch and Homebrew install/upgrade remain unverified. Windows CI checks compilation,
tests and smoke packaging, not Windows runtime support.
